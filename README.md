# Rhinoplasty Landmark Detection

Deep learning-based facial landmark detection for standardized rhinoplasty photography views (frontal, lateral, profile, worm's eye, superior).

## Landmarks
glabella, nasion, pronasale, subnasale, superior labiale, tip defining point (L/R), alare (L/R),  menton

## Data
Images and annotations are not included in this repository (patient data). 

## Structure
See `src/rhinolandmarks/` for model, dataset, and utility code. Training run via Colab notebooks in `notebooks/`.
